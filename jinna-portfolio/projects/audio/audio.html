I created a night sky-inspired web application audio visualizer using JavaScript and Canvas API. The game loop tracks featured on the website itself are as follows: an explore theme for a cathedral, one instance of a combat loop set in the same world, and one instance of a chase loop, also set in the same world. These were also created using Pro Tools. I have also done various audio projects using Reaper, Max, Ableton, and Logic Pro. I've included a link, if you'd like to listen!
